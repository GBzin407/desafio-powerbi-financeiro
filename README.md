# Desafio Power BI - Análise Financeira

Projeto desenvolvido durante o bootcamp da DIO, replicando um relatório de vendas
com Power BI e criando uma terceira página autoral com visuais de mapa e pizza.

## Conteúdo
- Mapa 1: Vendas e Unidades Vendidas por País
- Mapa 2: Lucro por País
- Gráfico de pizza: Lucro por Segmento

## Arquivos
- `sample_financial.pbix` - relatório Power BI
- `Financial_Sample.xlsx` - base de dados
- Scripts SQL de exercícios complementares

Projeto original: https://github.com/julianazanelatto/power_bi_analyst
